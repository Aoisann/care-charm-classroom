ことばの手あて — 使い方

1. dist/index.html をダブルクリックしてブラウザーで開きます。
2. テスト例を押すか、「痛い」にあたる短い語を入力します。
3. 曖昧な入力だけ、言語・地域を選びます。
4. 「やめる」で入力と音声が止まり、「再開」は本人が選べます。
5. 「人に相談する」は短い日本語を表示するだけで、自動送信しません。

文字入力は外部送信・保存されず、有料APIも使いません。任意の読み上げはブラウザー／OSの音声サービスに依存するため、利用できる声・対応言語・処理方法は端末によって異なります。女性の声は保証されません。
授業のテスト記録とKoshio講演との接続は、実施・確認後に記入してください。
